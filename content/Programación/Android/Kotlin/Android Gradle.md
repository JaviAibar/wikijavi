Es una herramienta de build que automatiza el proceso de construir y publicar la app

## Proceso que sigue

1. Gradle lee el archivo de construcción `build.gradle` (dependencias, build types)
2. Se descarga y resuelve las dependencias
3. Compila el código
4. Genera el apk
5. Instala el apk en el movil o emulador y lo ejecuta
